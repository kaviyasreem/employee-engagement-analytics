# Employee Engagement Analytics Dashboard

## Project Title
A Study on the Impact of Hybrid and Remote Work on Organisational Structure and Employee Engagement.

## Project Description
This project analyses employee engagement, organisational structure, productivity and work-life balance based on a UG research study involving 140 respondents.

## Objectives
- Analyse employee engagement in different work modes.
- Study organisational structure and communication.
- Understand work-life balance and productivity.
- Visualise questionnaire responses.
- Present statistical results from the original research report.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Dashboard Features
- Respondent demographic analysis
- Interactive charts
- Questionnaire response analysis
- Chi-square test results
- Pearson correlation results

## Dataset
The dataset contains aggregate response counts from the original UG project. It does not contain individual respondent records.

## How to Run
Install the packages:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py
